# ローカル編集版のエフェクトプラグイン v1

画面の「プラグイン → 読み込む」からJSONファイルを追加します。選択中のクリップに適用すると、プレビューとMP4書き出しに反映され、プロジェクトにもパラメーターが保存されます。

```json
{
  "version": 1,
  "name": "シネマ・ソフト",
  "description": "落ち着いた彩度とコントラスト",
  "effects": {
    "brightness": 0.02,
    "contrast": 0.94,
    "saturation": 0.8
  }
}
```

- `version`：1
- `name`：1〜80文字の表示名
- `description`：説明。保存時に160文字まで保持
- `brightness`：-0.5〜0.5、既定0
- `contrast`：0〜2、既定1
- `saturation`：0〜3、既定1

上記以外のエフェクトキー、文字列の数値、NaN等は受け付けません。1クリップにつき1つのカラー設定を適用します。別のプラグインを適用すると上書きされ、元に戻す操作で復元できます。

プラグインは任意コードを実行する仕組みではなく、ホストが対応する演算の宣言形式です。外部の実行可能ファイル、DLL、JS、Pythonを読み込みません。第三者製OpenFX・VST3・CLAPとは互換性がありません。

既存の `PLUGIN_SDK_JA.md` と `sdk/include/lattice_plugin.h` は将来のネイティブ連携用設計です。そのプロセス分離や他形式ホストはこのローカル編集版には接続されていません。


## 標準エフェクトの追加（16種類）

- カラー: 鮮やか、パステル、ノワール、ローキー、ハイキー、くすみカラー。
- 色変換: セピア、クールブルー、アンバー、ネガ反転。
- 映像効果: ビネット、ポスタリゼーション、モザイク、走査線。
- アニメーション: 波紋ウェーブ、光のパルス。

既存の3種類と合わせて19種類です。プラグインパネルの検索と分類で絞り込めます。
カラー設定とGLSLシェーダーを各1つ併用でき、同じ種類の適用は置き換えになります。シェーダーは適用前にコンパイルし、失敗時は既存の設定を保持します。解除は「シェーダーを編集」から無効化、カラーは「カラー効果を解除」です。設定・シェーダーコードはプロジェクトに保存され、共通レンダラーによる書き出しにも反映されます。

これらは内蔵プリセットです。外部JSON v1の読み込み仕様は従来通りカラー設定のみです。
