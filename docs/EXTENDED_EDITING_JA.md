# 拡張編集ガイド

## レイヤーとキーフレーム

下部には「レイヤー編集」と「キーフレーム」の2つのタブがあります。パラメーター行をレイヤー一覧の下に展開しないため、レイヤーが増えても数値編集が遠くへ押し出されません。

1. レイヤー編集で素材を選びます。左右ドラッグで配置時刻、上下ドラッグでレイヤーを変更します。上のレイヤーほど前面です。Zは見かけの大きさを変え、重なり順を上書きしません。同じレイヤーでは後から始まる素材が前面です。
2. キーフレームタブに切り替えます。選択素材とそのパラメーターだけを表示します。
3. 再生位置を決め、インスペクターの◇またはパラメーター行の＋でキーを追加します。空白のキー行をダブルクリックしても追加できます。
4. 時刻を進めて数値を変更します。すでにキーのあるパラメーターはその時刻にキーを追加・更新します。「自動キー」をオンにすると未アニメーションの項目にもキーを作ります。
5. ◆を横にドラッグすると時刻が変わります。選択したキーから次のキーまでの補間を「直線移動／なめらか／瞬間移動」で選べます。右クリックまたは「キーを削除」で削除します。

クリップを分割しても、補間カーブとシェーダーの時間は連続します。分割前のカーブを保持するため、内部には素材範囲外のキーが残る場合があります。範囲外のキーはタイムラインに表示しません。

## 標準素材

左側の標準素材から四角形・円・三角形・星・背景・テキスト・カメラ制御・クリッピングを追加します。選択素材があれば1つ上のレイヤー、なければ最下位レイヤーを使います。初期長は5秒です。

テキストは日本語・改行・色・文字サイズ・左右中央揃えに対応します。文字・図形の色・幅・高さ・文字サイズは入力中にプレビューへ反映されます。日本語IMEの変換中も入力欄とフォーカスを維持します。Windowsの日本語フォントを使用します。

カメラ制御は時間を持つ素材です。スケールで出力映像のズーム、X/Yでパン、回転で画角を変更します。キーを付ければズームアニメーションになります。同時に複数のカメラが有効な場合、最上位レイヤーのカメラを使用します。

クリッピング素材を対象より上のレイヤーに配置すると、図形の内側だけを表示します。「切り抜き対象」が自動の場合、直下の有効な表示素材1つを対象とします。インスペクターで特定の素材を指定することもできます。複数のマスクは交差領域を表示します。マスクは硬い境界の図形クリップで、ぼかしや任意画像のアルファマスクではありません。

## 編集用カメラ

3D空間ではドラッグで視点を回転、ホイールと＋−で表示を拡大縮小します。Alt＋ドラッグで素材を移動できます。出力画面では通常ドラッグで素材を移動します。ドラッグ中に文字は選択されません。入力欄やコード欄の文字選択は通常どおり可能です。

編集用の視点回転・ズームは出力されません。出力を拡大縮小するにはカメラ制御素材を使ってください。

## カスタムシェーダー

映像・図形・テキストを選び「シェーダー」を開きます。WebGL 1 / GLSL ES 1.00の `vec4 effect(vec2 uv, vec4 color)` を定義します。

- `uv`: 0〜1のテクスチャ座標（原点は左下）
- `color`: 元の色（RGBA）
- `sampleSource(uv)`: 元画像を任意の座標で読む
- `u_time`: 素材内の秒数。分割後も連続
- `u_resolution`: 処理先のピクセル寸法

「コンパイルしてプレビュー」で確認し、「選択素材に適用」で反映します。コンパイルに失敗しても直前の適用コードは変更しません。1素材につき1つのシェーダーです。色反転・波紋・ビネットのサンプルを同梱します。外部テクスチャ、多段レンダーパス、カスタムuniform UIは未対応です。

プレビューと書き出しに同じ処理を使用します。プロジェクトにはコードそのものを保存するため、再読み込みで復元されます。GLSLはブラウザーのGPU上で動作し、ファイルやネットワークを操作するJavaScriptではありません。

## 保存・読み込み

「名前を付けて保存」は、その時点のプロジェクトを新しいスナップショットとしてこのPCに保存します。「開く」の一覧から戻せます。JSONファイルのダウンロードと読み込みも可能です。自動保存は現在の作業状態を保持します。新規作成前には現在のプロジェクトを名前付き保存します。

キーフレーム、図形、文字、マスク、カメラ、GLSL、レイヤー構成を保存します。動画・音声本体は `.lattice-local/media`、メタデータは `.lattice-local/assets.json` にあります。別PCへはプロジェクトJSONだけでなく `.lattice-local` 一式をコピーしてください。

書き出しは4KまたはフルHD、30fpsのMP4です。フレームの生成中は中止できます。中止した作業データは削除され、プロジェクトは保持されます。ブラウザーが閉じられて送信が途絶えた場合は、一定時間後にFFmpegセッションを終了します。


## 操作性の改善

- インスペクターは文字・色・サイズを先に表示し、タイミングやエフェクトは折りたたみ式です。
- 素材の「中央に配置」「前へ」「後ろへ」で配置と重なり順を調整できます。
- 「複製」または Ctrl+D は選択素材の直後にコピーを作成します。キーとシェーダーも引き継ぎます。
- 素材の右クリックから複製、前後移動、先頭への移動、キー編集、分割、削除ができます。
- タイムラインの「全体表示」（F）は長い映像も表示範囲に収めます。Ctrl＋ホイールでも拡大縮小できます。
- 「吸着 ON」でドラッグやトリムが素材の端・再生位置に吸着します。Altを押しながらドラッグすると一時解除します。
- タイムライン上端を上下にドラッグして高さを変更します。ダブルクリックで標準の高さに戻ります。
- ダブルクリックした素材をキーフレーム表示で開けます。キー表示は選択素材の行に限定します。
- 再生位置に選択素材が存在しない場合、プロパティ上部の案内から素材の先頭に移動できます。
- Shift＋左右キーは10フレーム移動、Home / End は先頭 / 最後です。「⌨」で一覧を確認できます。


## 曲線編集
素材を選択してタイムラインの「曲線編集」を押します。スケール・位置・回転・不透明度を選び、「開始・終了にキー」で両端のキーを作成します。点をドラッグするか、時刻と値を入力して編集します。最初のキーを選び「自由なベジェ曲線」にすると、橙色のハンドルで加減速を調整できます。「ゆっくり開始」「ゆっくり終了」等のプリセットもあります。補間は選択キーから次のキーに適用します。制御点は0〜1内で、オーバーシュートは非対応です。保存・再読み込み・分割・書き出しにも曲線を保持します。

## 出力サイズ
書き出し画面の解像度で4K・フルHD・HD・縦長・正方形・カスタムを選べます。カスタムは幅と高さを128〜4096の偶数で指定し、総画素数は3840×2160以下です。編集キャンバスは16:9のまま、異なる縦横比では全体を収めるか、中央を切り抜くか選択できます。出力設定は次回も保持されます。GPUによって対応する最小サイズ等が異なり、エラー時はCPUエンコーダーを選んでください。
